# Google Stitch — UniDate Master Prompt

Create a complete, polished, mobile-first university dating and social discovery application named **UniDate**.

## Visual direction
Use the supplied reference images as visual inspiration. Build a consistent design language using:
- Burgundy `#970D19`
- Deep burgundy `#650914`
- Accent red `#EF202B`
- Blush pink `#FAD4D6`
- Soft background `#FFF3F3`
- White `#FFFFFF`
- Primary text `#202024`
- Secondary text `#77777F`

Use Poppins for headings and Inter for body text. Use clean white cards, rounded corners, subtle shadows, generous spacing, elegant burgundy buttons, and restrained red/pink decorative accents. Avoid clutter and excessive gradients.

## Product audience
Adult university students aged 18 and above. The product supports dating, friendship, and campus social discovery.

## UX requirements
- Use a five-item bottom navigation: Discover, Likes, Chats, Events, Profile.
- Design reusable buttons, inputs, cards, chips, badges, dialogs, and navigation.
- Include loading, empty, error, disabled, and success states.
- Keep forms clear and mobile-friendly.
- Use realistic sample content but do not present sample people as real users.
- Use a 390 px wide mobile frame as the initial reference and create responsive variants.
- Keep student verification documents private and separate from public profile media.
- Provide obvious block, report, and privacy controls.
- Do not show precise live location.
- Do not create a match unless both users have liked each other.
- Keep safety features available without a paid subscription.

Deliver a coherent design system and a connected set of screen designs, not unrelated mockups.
